1. 从全文检索开始说起

在项目开发过程中，用到全文检索的场景还是很常见，一谈到全文检索。脑子里肯定第一个浮现的就是 es 了。这个无可厚非，毕竟 es 在这方面可以说是公认的，通过分词器，可以很好的满足我们项目开发中的一些复杂的搜索场景。由于这不是本篇的重点，就不做过多的描述。下面我们来看看 MySQL 中的全文检索。

2.3 方案二，MySQL的全文检索。

2.3.1 数据库版本

自MySQL5.7.6版起，MySQL将ngram全文解析器作为内置的服务器插件当MySQL数据库服务器启动时，MySQL会自动加载该插件。 MySQL支持用于InnoDB和MyISAM存储引擎的ngram全文解析器。

2.3.2 ngram_token_size 设置

ngram_token_size的值表示每个词是连续两个字的序列。 举个例子来说明该参数的作用。 如有这么一句话。
我在上海工作

当ngram_token_size的值为1时，分词结果为：我，在，上，海，工，作
当ngram_token_size的值为2时，分词结果为：我在，上海，工作
当ngram_token_size的值为2时，分词结果为：我在上,海工作

配置方式有两种；
1，修改配置文件；

1
2

[mysqld] 
ngram_token_size=2

2，设置数据库启动参数

1

mysqld --ngram_token_size=2

CREATE TABLE `site_info` (
  `site_id` varchar(100) NOT NULL COMMENT '门店id',
  `address` varchar(255) DEFAULT NULL COMMENT '门店地址',
  PRIMARY KEY (`site_id`),
  FULLTEXT (address) WITH PARSER ngram
) ENGINE=InnoDB DEFAULT CHARSET=utf8 COMMENT='场所表';

3. 总结

MySQL全文索引在实际开发中用的情况不多，但是在某些特定场景，如数据量小，项目小，又没有必要去引入es等搜索引擎来增加系统的复杂性的情况下。MySQL全文索引未尝不是一个很好的选择。
