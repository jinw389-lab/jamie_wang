1.自己动手实现观察者模式

①. 从一个小故事说起到实现

我们就拿博友关注博客来说，比如在开源中国上，我可以关注博主，博主发布了新的博文，我会收到推送消息，然后我可以点击观看博客。下面就用来模拟一下这个场景。

/**
 * 博主类（被观察者）
 * @author jamie
 */
public class Blogger {

    /**
     * 订阅者列表
     */
    private List<BlogObserver> blogObservers = Lists.newArrayList();

    /**
     * 添加订阅者
     * @param blogObserver
     */
    public void addObserver(BlogObserver blogObserver){
        blogObservers.add(blogObserver);
    }

    /**
     * 博主发布博客方法
     */
    public void push(){
        System.out.println("博主发布博文");
        for (BlogObserver blogObserver : blogObservers) {
            blogObserver.read();
        }
    }
}

/**

 * @author jamie
 */
public class BlogFriend implements BlogObserver{
    private String name;
    public BlogFriend(String name) {
        this.name = name;
    }
    @Override
    public void read() {
        System.out.println(name+" 阅读博文");
    }
}

}

②. 引发事件

针对上面的实现，可以抽象出事件的概念，在博主发布了博文后，不同的观察者查阅博文，这就是一个事件所以我们要把发布博客抽象为事件。下面来做具体实现。

场景：博主发布了java博文后，张三认真阅读，李四大概浏览，博主发布了操作系统博文后，张三不阅读，李四还是大概浏览；博客官方发布资讯，张三李四都选择忽略。
对上面代码进行改造

  • 添加事件类
    一个事件必须有事件源，好比这个例子，这个发布博文这个事件是由博主发起的，所以事件源就是博主。但是发布这个事件，不一定是博主发起。就好比发文章除了博客的博主，开源中国官方也可以发布一些资讯等，这同样是一个发布事件，但是一个观察者针对不同的事件源的动作也是不一样的。比如：博主发布博文就观看，但是开源中国官方发布资讯，我选择忽略

        setChanged();
        notifyObservers(blogEvent);
    }
}

    @Component
public class BlogFriendListener implements ApplicationListener<PushEvent> {

  //观察者对象集合
  private List<BlogFriend> blogFriendList = Lists.newArrayList();

  public void addBlogFriend(BlogFriend blogFriend){
      blogFriendList.add(blogFriend);
  }

  @Override
  public void onApplicationEvent(PushEvent event) {
      String topic = event.getTopic();
      Object o = event.getSource();
      for (BlogFriend blogFriend : blogFriendList) {
          String name = blogFriend.getName();
          if(o instanceof Officialer){
              String OfficialTem = "%s 忽略官方发布的%s资讯";
              System.out.println(String.format(OfficialTem,name,topic));
              continue;
          }
          switch (topic){
              case "java":
                  if("张三".equals(name)){
                      System.out.println(String.format("%s 认真阅读博主发布的%s博文",name, topic));
                  }else if("李四".equals(name)){
                      System.out.println(String.format("%s 大概浏览%s博文",name, topic));
                  }
                  break;
              case "操作系统":
                  if("张三".equals(name)){
                      System.out.println(String.format("%s 不阅读%s博文",name, topic));
                  }else if("李四".equals(name)){
                      System.out.println(String.format("%s 大概浏览%s博文",name, topic));
                  }
                  break;
              default:
                  break;
          }
      }
  }
}
