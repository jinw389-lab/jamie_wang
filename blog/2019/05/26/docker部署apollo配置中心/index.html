docker部署apollo配置中心

Posted by jamie Blog on 2019-05-26 · 阅读 -- 次

1.概述

公司前段时间决定用docker部署微服务项目，配置中心采用的是携程的apollo，要将其迁移到docker部署。在之前配置中心单独部署，由于以前配置中心这块是我在负责搭建，所以现在也由我进行迁移。
之前也没怎么用过docker。这里也仅仅是先在自己的电脑上小试牛刀。

2.步骤

1.获取apollo源码

1

git地址：https://gitee.com/lepdou/apollo.git

2.修改Meta服务地址

由于我这里只考虑dev环境，所以执行修改dev_meta地址。
打开项目中的scripts目录下的build.sh脚本文件，将dev_meta=http://localhost:8080修改为dev_meta=http://apollo-configservice:8080
apollo-configservice是我们为config设置的容器名称。docker服务间访问可以通过容器名称访问。

执行命令：docker-compose up -d
当出现
成功！ 部署完成！访问localhost:8070大功告成！然而并不能如意！
执行docker ps发现只有mysql启动成功怎么回事呢？ 查看config日志

1

HHH000342: Could not obtain connection to query metadata : Unknown database 'ApolloConfigDB'

发现没有找到数据库ApolloConfigDB。
的确从头到尾也没有创建数据库啊，那么接下来就创建数据库

5.创建ApolloConfigDB与ApolloPortalDB数据库

navicat连接mysql
连接失败。这里由于安装的mysql8.需要修改密码的加密规则或重置密码 执行脚本进入容器：

1

docker exec -it mysql bash

等录数据库

1

mysql -uroot -p

执行密码修改

1

ALTER USER 'root'@'%' IDENTIFIED WITH mysql_native_password BY 'root';

然后navicat测试连接成功！ 然后执行apollo项目下的script/sql下的apolloconfigdb.sql，apolloportaldb.sql文件 修改apolloconfigdb数据库中的serverConfig表中eureka.service.url字段修改为： http://apollo-configservice:8080/eureka 成功后，再次执行docker-compose up -d 然后等待启动成功，访问8070端口登陆！
