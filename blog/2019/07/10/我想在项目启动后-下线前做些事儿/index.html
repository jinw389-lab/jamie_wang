我想在项目启动后，下线前做些事儿

Posted by jamie Blog on 2019-07-10 · 阅读 -- 次

本篇仅作为工作归纳。

1.需求目标

有些场景我们需要在Spring 所有的bean 完成初始化后紧接着执行一些任务或者启动需要的异步服务

2.实现方案

1.j2ee 注解 启动前@PostConstruct 销毁前@PreDestroy 基于j2ee 规范
2.springboot 的 org.springframework.boot.CommandLineRunner
3.spring org.springframework.context.SmartLifecycle

2.实现例子

@Component
public class PostConstructTestClass {
    @PostConstruct
    public void start() {
        System.out.println("PostConstructTestClass start..............");
    }
    @PreDestroy
    public void stop() {
        System.out.println("PostConstructTestClass stop..............");
    }
}

@Component
@Order(1) //若有多个CommandLineRunner实现，则可以通过order来指定执行顺序
public class MyStartupRunner implements CommandLineRunner {
    @Override
    public void run(String... args) throws Exception {
        System.out.println("MyStartupRunner run ..............");
    }
}

此种方式只能实现在项目启动成功后，执行run方法。做不到在项目关闭执行。

@Component
public class MySmartLifecycle implements SmartLifecycle {
    private boolean isRuning;
    @Override
    public void start() {
        System.out.println("MySmartLifecycle start..............");
        isRuning = true;
    }
    @Override
    //只有在isRunning方法返回true才会执行
    public void stop() {
        System.out.println("MySmartLifecycle stop..............");
        isRuning = false;
    }
    @Override
    public boolean isRunning() {
        return isRuning;
    }
}

这种方式在类装载到容器成功后，执行start函数。项目下线执行stop函数。
