总结一下springboot中加载配置的几种方式

Posted by jamie Blog on 2022-07-10 · 阅读 -- 次

1.描述

在实际开发项目的工程中，我们经常会将某一项信息放入配置文件中，这样可以提高代码的灵活性。那么在SpringBoot项目中，有哪些方式可以加载配置文件中的配置呢?以下是我们常见的几种形式。

2.常见方式

2.1. @Value注解形式

该种形式可以说是最常见的一种，使用起来也是最简便的。我们只需要在属性字段中加上Value注解并写上对应的key，spring在启动的时候则可以自动为该属性设置为配置文件中的值。

比如我在配置文件中添加如下配置

1
2

test:
  name: wj

那么在要读取配置的地方使用如下代码，将配置值读入属性name。

1
2

    @Value("${test.name}")
    private String name;

该种方式的最大优势就是开发简单便捷。

缺点就是不能批量添加，如若有很多配置，则需要写多个属性，并在每个属性上都要配置注解，并指定对应的key，如此下来就变得很繁琐；还有就是若没有该配置的key，则会启动报错，要手动配置默认值。

如上述例子，配置默认值为wj则要在表达式后面添加:后面写默认值。

1
2

@Value("${test.name:wj}")
private String name;

2.2. @ConfigurationProperties

@Value的方式缺点存在非常多的配置时，配置起来就非常麻烦。为了解决该问题，Spring提供了ConfigurationProperties注解。

若存在如下配置

1
2
3
4

test:
  id: 100
  name: wj
  age: 25

定义TestConfig类，记得一定要有set方法。我这边直接使用lombok的Data注解了。

1
2
3
4
5
6
7
8

@ConfigurationProperties(prefix = "test")
@Configuration
@Data
public class TestConfig {
    private Integer id;
    private String name;
    private Integer age;
}

2.3. 注入Environment对象

此种方式用起来也是极为简单，直接将Enviroment对象注入，在获取配置时，通过getProperty方法即可获得对应的配置值。

注入对象

1
2

    @Resource
    private Environment environment;

或者实现EnvironmentAware接口，重写setEnvironment也可以获得

1
2
3
4

    @Override
    public void setEnvironment(Environment environment) {
        this.environment = environment;
    }

获取配置时使用environment.getProperty方法获取对应的配置值。

Environment比较强大，除了可以获取配置，还可以设置添加配置，获取激活的配置文件，亦或者在自定义组件中广泛使用到。

2.4. @PropertySources

该注解可以在应用启动类上直接使用。如示例加载了a.properties配置

1

@PropertySources(value = @PropertySource("classpath:a.properties"))

这种方式有一个很大的缺陷，只能加载properties文件的配置。

2.5. 构建PropertySourcesPlaceholderConfigurer bean

如下是加载classpath下面的a.yml配置文件的代码。

1
2
3
4
5
6
7
8

	@Bean
	public static PropertySourcesPlaceholderConfigurer yamlConfigurer() {
		PropertySourcesPlaceholderConfigurer propertySourcesPlaceholderConfigurer = new PropertySourcesPlaceholderConfigurer();
		YamlPropertiesFactoryBean yamlPropertiesFactoryBean = new YamlPropertiesFactoryBean();
		yamlPropertiesFactoryBean.setResources(new ClassPathResource("a.yml"));
		propertySourcesPlaceholderConfigurer.setProperties(Objects.requireNonNull(yamlPropertiesFactoryBean.getObject()));
		return propertySourcesPlaceholderConfigurer;
	}

2.6. java原生形式

这种方式就不局限与SpringBoot了，是通过最原生的java形式获取。在开发中基本很少使用。

1
2
3

Properties properties = new Properties();
InputStreamReader inputStreamReader = new InputStreamReader(ClassLoader.getSystemClassLoader().getResourceAsStream("a.properties"), StandardCharsets.UTF_8);
properties.load(inputStreamReader);

3.总结

以上总共总结了6中在Springboot项目中获取配置的方式，前面三种总的来说是经常会使用到的方式，后面三种用的场景非常少。在实际项目开发过程中，我们可以根据具体场景选择合适的形式。
