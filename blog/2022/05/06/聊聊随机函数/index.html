1. JAVA 中的 Math.random()

在 JAVA 中获取随机数一般采用 JDK 封装好的 random 函数, 该函数返回一个0到1，左闭右开的随机小数，并且是等概率获取。

1.1 验证函数是等概率获取随机数

循环获取100000次，并记录一下得到的数值小于0.3的概率，若函数随机等概率返回一个 [0,1) 的小数，那么小于0.3的概率就为0.3。所以写如下程序，看执行结果是否近似0.3。若是，则为等概率返回，否则不是。

public static void main(String[] args) {
        int count = 0;
        int times = 100000;
        for (int i = 0; i < times; i++) {
            double random = Math.random();
            if(random < 0.3){
                count++;
            }
        }
        System.out.println((double) count / (double)times);
    }

执行结果为 0.30133 ,趋近于 0.3。可以得到以上验证的结果。

那么以此类推，若统计小于 0.4 的呢? 我这边执行结果为：0.40155。

2. 如何得到[0,8)随机数

根据JAVA提供的数据函数，我们只能得到一个[0,1)的随机数，那么如何得到[0,8)的随机数呢？

直接乘以8就行了。

1

Math.random() * 8;

那么我们来验证一下是否是随机获取？ 直接将之前的代码修改一下即可，我们计算小于4的概率是否是0.5即可。

            if(random < 4){
                count++;
            }
        }
        System.out.println((double) count / (double)times);
    }

将代码中的小于4改为小于5，若得到的概率为5/8=0.625，则也可以说明是等概率。

执行代码结果为：0.62433。

所以我们基于以上可以得出一个结论，若要获取一个[0,K)的随机数，则直接可以 [0,1) * K。

1

Math.random() * K;

若要获取 [0,K] 闭区间呢？

1

Math.random() * (K + 1);

3. 如何从[0,X)—>[0,x平方)随机数

我们java中Math.random()获取的随机数毕竟是线性的，我们现在要获取到x平方的随机数。

public static void main(String[] args) {
        int count = 0;
        int times = 1000000;
        double x = 0.7;
        for (int i = 0; i < times; i++) {
            double random = xToProw2();
            if(random < x){
                count++;
            }
        }
        System.out.println((double) count / (double)times);
        System.out.println(Math.pow(x,2));
    }

    /**
     * [0,x)---> [0,x平方)
     * @return
     */
    private static double xToProw2(){
        return Math.max(Math.random(),Math.random());
    }

打印的统计结果为：

1
2

0.48993
0.48999999999999994

基本一致，则可以得出结果，我们的函数是正确的。

注意：x小于1
那么是为啥呢？分析一下，max函数中有两次取随机数，并且两次都是在[0,x)范围内，取两次，就是x平方。

举例：若要调用获取小于0.3的数，则调用两次都在小于0.3范围内的概率为 0.3*0.3=0.09

为啥不是Math.min？ 分析一下，若是min，则就是两次获取随机数的概率都要是大于0.3，所以概率为0.7*0.7=0.49。那么除了两次获取随机数都大于0.3的情况，剩余其他的情况发生的概率为1-(0.7*0.7)=0.51，这是从[0,x)—>[0,1-(1-x)平方)。

4. 从1-5随机到1-7

那么如何从1-5随机到1-7呢？已知一个函数f可以获取得到随机等概率1-5的数，那么我们通过这个基准函数，如何变幻得到一个能够获取1-7的函数呢?

首先我们要构建一个对数器，将1-5改造为0-1;

    /**
     * [1-5]
     *
     * @return
     */
    private static int f() {
        return (int) (Math.random() * 5) + 1;
    }

    /**
     * 对f函数进行改造封装，变幻得到0-1的对数器
     */
    private static int f1(){
        int f = f();
        return f<=2 ? 0 : f >= 4 ? 1 : f1();
    }

下面来解释一下 f<=2 ? 0 : f >= 4 ? 1 : f() 由于f是获取1-5的随机函数，则该f函数的结果集为[1,2,3,4,5],那么我们把获取到1和2的结果影射为0,4和5影射为1，结果为3的话，就再次递归调用f函数，直到不是3为止。

    private static int f2() {
        return (f1() << 2) + (f1() << 1) + f1();

那么为啥f2如此实现呢?这里采用了二进制位运算的方式，由于f1可以等概率获取0和1的随机数，并且三位二进制位可以表示的数据位0-7。

这里只是得到0-7的随机数，如何再次通过变幻得到1-7呢。我们可以这样做。随机得到0时，然后再次递归调用，直到不是0为止，相当于把得到0的概率均分到其他数。有了上面写f1的经验，这个就比较简单了。

    private static int f3() {
        int f = f2();
        return f == 0 ? f3() : f;

5. 总结

我们从java的随机函数random开始说起，谈到了求各种随机函数获取的变化逻辑，在算法岗位中，这种自己创建随机对数器使用的情况很多，毕竟他们写出来的算法，要验证其正确性，就要在一定的数据上来做实验，而且这些数据都必须是随机概率取得，这个时候对数器就派上用场了。不过在我们业务开发的时候，这种应用基本很少，就当来涨涨见识了，增加视野，开拓思路。
