单元测试

Posted by jamie Blog on 2020-04-29 · 阅读 -- 次

1. 单元测试的优点

①. 方便代码重构

代码重构往往是牵一发而动全身的。当修改底层数据结构时，上层服务经常会受到影响。有时候只是简单地修改一个字段名称，就会引起一系列错误。但是在有单元测试保障的前提下，重构代码时我们会很自然地多一分勇气。

①. 提升编码质量

单元测试可以将代码中的缺陷尽早暴露出来，因为越早发现的问题，修复的成本也就越低。

单元测试失败能够帮我们快速的排查和定位问题，使问题在被带到现实之前完成修复。

2. 规范与基本准则

①. 全自动

测试用例通常会被频繁地触发执行，执行过程必须完全自动化才有意义。如果单元测试的输出结果需要人工介入检查，那么它一定是不合格的。单元测试中不允许使用 System.out 来进行人工验证，而必须使用==断言==来验证。

②. 避免用例依赖

为了保证单元测试稳定可靠且便于维护，需要保证其==独立性==。用例之间不允许互相调用，也不允许出现执行次序的先后依赖。

③. 粒度足够小

编写单元测试时要保证测试粒度足够小,这样有助于精确定位问题

④. BCDE原则
  1. B: Border 边界值测试，包括循环边界、特殊取值、特殊时间点、数据顺序等。
  2. C: Correct 正确的输入,并得到预期的结果。
  3. D: Design 与设计文档相结合，来编写单元测试。
  4. E : Error 单元测试的目标是证明程序有错，而不是程序无错。为了发现代码中潜在的错误,我们需要在编写测试用例时有一些强制的错误输入（如非法数据、异常流程、非业务允许输入等）来得到预期的错误结果。

③. @Before，@After

在一个单元测试类中，若每个单元测试都要执行一些前置，后置逻辑，则可以将这些逻辑独立成方法，并打上相应注解。

例如：要执行一批单元测试，但是执行之前要做一些基础数据，后面的测试都是要在这些数据之上做。

public class User {
    private Long id;
    private String name;
    //省略 get set方法
}

@Service
public class UserService {
    //模拟数据库
    private List<User> users = new ArrayList<>();

    public User findById(Long id) {
        return users.stream().filter(r->r.getId().equals(id)).findAny().orElse(null);
    }

    public void save(User user) {
        users.add(user);
    }
    public void delById(Long id) {
        int size = users.size();
        for (int i = size - 1; i >= 0 ; i--) {
            if(users.get(i).getId().equals(id)){
                users.remove(i);
            }
        }
    }
}

//测试用例
@RunWith(SpringRunner.class)
@SpringBootTest(classes = Main.class)
public class UserServiceTest {
    @Autowired
    private UserService userService;
    //插入测试初始数据
    @Before
    public void prepareData() {
        //插入数据
        User user = new User();
        user.setName("张三");
        user.setId(1L);
        userService.save(user);
    }

    @Test
    public void testFindById() {
        User user = userService.findById(1L);
        Assert.assertNotNull(user);
        Assert.assertEquals(user.getName(),"张三");
    }

    @Test
    public void testDelById() {
        userService.delById(1L);
        User user = userService.findById(1L);
        Assert.assertNull(user);
    }
}

@RunWith(SpringRunner.class)
@SpringBootTest(classes = Main.class)
public class AServiceMockTest {
    @Autowired
    private AService aService;
    @MockBean
    private BService bService;
   
    @Before
    public void setUp() {
        //doSmthing方法。返回mockBServce
        Mockito.when(bService.doSmthing()).thenReturn("mockBServce");
    }
    
    @Test
    public void test() {
        aService.doSmthing();
    }
}

@RestController
public class TestController {

    @GetMapping("/testApi")
    public String testApi(String param){
        return param;
    }

    @PostMapping("/testApi2")
    public User testApi(@RequestBody User user){
        return user;
    }
}

//编写测试
@RunWith(SpringRunner.class)
@SpringBootTest(classes = Main.class)
public class AServiceMockTest {

    private MockMvc mockMvc;

    @Before
    public void setUp() {
        mockMvc = MockMvcBuilders.standaloneSetup(new TestController()).build();
    }

    @Test
    public void testApi1() throws Exception{
        MockHttpServletRequestBuilder req = MockMvcRequestBuilders.get("/testApi").param("param", "1")
                .contentType(MediaType.ALL)
                .accept(MediaType.APPLICATION_JSON_UTF8);
        ResultActions perform = mockMvc.perform(req);
        perform.andExpect(MockMvcResultMatchers.status().isOk());
        MvcResult mvcResult = perform.andReturn();
        MockHttpServletResponse response = mvcResult.getResponse();
        String s = new String(response.getContentAsByteArray(), "UTF-8");
        //判断结果
        Assert.assertEquals(s,"1");
    }
    
    @Test
    public void testApi2() throws Exception{
        String jsonReq = "{\"name\":\"testName\",\"id\":11}";
        MockHttpServletRequestBuilder req = MockMvcRequestBuilders.post("/testApi2")
                .contentType(MediaType.APPLICATION_JSON).content(jsonReq);
        ResultActions perform = mockMvc.perform(req);
        perform.andExpect(MockMvcResultMatchers.status().isOk());
        MvcResult mvcResult = perform.andReturn();
        MockHttpServletResponse response = mvcResult.getResponse();
        //结果校验
        JSONAssert.assertEquals(jsonReq, response.getContentAsString(),false);
    }
}
⑥. 单元测试回滚

在进行单元测试的时候，希望单元测试的数据对其他测试不造成影响，可以在测试类上或者方法加上注解@Transactional，在方法上加上@Rollback。Transactional注解会让Spring会在@Before 和 @After之间增加事务，在执行完成单元测试后，数据会自动回滚。
