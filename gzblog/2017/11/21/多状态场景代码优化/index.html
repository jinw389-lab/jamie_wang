多状态场景代码优化

1.假设场景1

根据不同的状态码返回不同的数据

  1. if

    if(state == 1){
 return new ResOne();

if(state == 2){
 return new ResTwo();

    switch(state){
 case 1:
     return new ResOne();
 case 2:
     return new ResTwo();
}

    以上两种做法都不易扩展，且篇幅过多时维护成本很高。

  3. 封装到map
    map的key为状态，value为具体对象；
    所以取值时只需通过key获取对象即可。这种方式较暴力也很好理解！比前两种都要好得多。

public class Context {
    public static final  State oneState = new OneState();
    public static final  State twoState = new TwoState();

    private  State state;
    public void setState(State state){
        this.state = state;
    }

    public Object get(){
        return state.get();
    }
}
